# Drop your video files here

Put `.mp4` files in this folder. Reference them in `src/data/videos.ts`
as `/videos/your-file.mp4`.

Naming tip: use lowercase with hyphens, no spaces. For example
`dominica-cbi-overview.mp4` rather than `Dominica CBI Overview.mp4`.

Recommended encoding for web playback:
- H.264 codec, AAC audio
- 1080p or 720p
- Around 5 to 10 MB per minute of video
- mp4 container

Posters (the still image shown before play) go in
`public/images/videos/` and are referenced as
`/images/videos/your-poster.png` in the entry's `poster` field.
